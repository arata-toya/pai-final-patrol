# GitHubへの追加と提出

V1の公開リポジトリを維持し、その下にaward_v3を追加します。ZIPにはaward_v3フォルダが入っています。V1のファイルは置き換えません。

## 1. ダウンロードと展開

pai_award_v3_public.zipをWindowsのデスクトップに保存します。次はすべて**Windows PowerShell**で実行します。

```powershell
Expand-Archive -LiteralPath "$env:USERPROFILE\Desktop\pai_award_v3_public.zip" -DestinationPath "$env:USERPROFILE\Desktop\pai_award_v3_public"
cd "$env:USERPROFILE\Desktop\pai_final_submission\pai_final"
Copy-Item -LiteralPath "$env:USERPROFILE\Desktop\pai_award_v3_public\award_v3" -Destination . -Recurse
```

同名の展開先やaward_v3が既にあるときは、既存フォルダを別名で保存してから行います。

## 2. 一覧を確認して公開

```powershell
git status --short
git add award_v3
git diff --cached --stat
git commit -m "Add V3 wall inspection patrol and evaluation records"
git push origin main
```

GitHubでaward_v3/README.md、説明PDF、models、scripts、runs_v3が表示されることを確認します。

公開先： https://github.com/arata-toya/pai-final-patrol/tree/main/award_v3

このURLは上記push完了後に利用できます。V3公開前に応募用リンクとして送らないでください。

## 3. トップページにもV3の案内を追加

リポジトリのREADME.mdの末尾に、次を追記します。すでに同じ案内があれば重ねて追加しません。

```markdown
## 優秀性選出向けの発展版

[AI壁面巡視ロボット V3：コード・評価・点検記録](award_v3/README.md)
```

編集後、README.mdをコミットしてpushします。

```powershell
git add README.md
git commit -m "Link V3 wall patrol from project README"
git push origin main
```

## 4. 動画と説明資料

- 採用動画：PAI_final_84140_V3.mp4、2分10秒。ZIPには動画自体は同梱していません。
- 説明PDF：award_v3/docs/説明資料_PAI最終課題_84140.pdf。
- 動画はYouTubeに新しい動画としてアップロードし、共有URLを取得します。旧V1の動画を削除する必要はありません。
- 応募フォームにはV3の動画URLと上記GitHubのV3フォルダURLを記入し、指定された説明資料を添付します。
- InPrivate等の未ログイン状態で、動画とGitHubの両方を開けることを確認します。

既に提出済みの通常課題と、優秀性選出用の応募先を区別してください。
